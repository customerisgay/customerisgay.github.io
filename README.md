# OS Simulator — React Edition v2

Experience Windows 11, Ubuntu, macOS and iOS in your browser. Fully mobile compatible.

## Features
- OS Selector — Windows 11, Ubuntu 24.04, macOS Sonoma, iOS
- Working File Manager, Browser (Chrome/Edge/Safari), Spotify (8 self-hosted songs), Terminal, Calculator, Notepad, Settings, Photos, Store, VS Code, Clock
- Mobile: windows open full-screen, touch drag, compact taskbar/dock, responsive layouts
- Songs are self-hosted in /songs/ so they play on mobile (Google Drive fallback included)

Built with React + Vite.
